File Scanner with Splunk

Python, watchdog, SQLite, Splunk HEC

Problem

Files land in a Downloads folder all day, and nobody checks them until something goes wrong.

What I did

Built a real-time scanner: it hashes every new file, scores its risk from type, location and entropy, quarantines anything flagged and sends each result to Splunk tagged with MITRE ATT&CK.

Result

Every file event becomes a searchable Splunk record that can trigger an alert, the same way a SIEM is used in a SOC.

Try a simplified version of its checks. The hash and entropy are worked out for real in your browser, and your own file never leaves your device.
